# Tài Liệu Kỹ Thuật `agy-tools`

Cấu trúc tài liệu chuẩn 5 tầng của dự án:

```text
docs/
├── 00_common/          # Quy chuẩn chung, thuật ngữ, công nghệ
├── 01_srs/             # Đặc tả yêu cầu tổng quan, tác nhân, yêu cầu phi chức năng
├── 02_basic_design/    # Kiến trúc hệ thống, hợp đồng CLI, quyết định kiến trúc (ADRs)
├── 03_features/        # Đặc tả chi tiết từng tính năng (FR/BR/AC, luồng xử lý)
└── 04_tasks/           # Kế hoạch triển khai và theo dõi tiến độ từng task
```
